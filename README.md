# A.T.L.A.S.
A.T.L.A.S. or the **A**tmospheric **T**elemetry & **L**ocalized **A**nalytic **S**ystem is a Weather Station which sends Air Quality, Humidity, Temperature, Barometric Sensors Data to an Local, Selfhosted NodeMCU Web Server with the advantage of Portability using Batteries. It interprets and reacts with the weather using an OLED Display which shows expressions like the EMO Robot.
## Why I Made this Project?
I Made this Project because we need to know about our surroundings, the air which we breathe, the Temperature and the Humidity and like most of us, we want to know whether it will rain or not. For this, The Data is represented in an Detailed, Easy to Understand form and for quicker and cutness look, the tiny OLED Screen will show different emotions or faces according to the given data. This can also be helpful for some people as the People with Lung Diseases can benefit for this as it sends out Air Quality Data which helps them to see whether the air is safe for them to breathe or not.
